# AGENTS.md — deploy

本文件是 `deploy` 的项目说明，**继承工具站根目录 `AGENTS.md` 的全部通用规范**。
两者冲突时，以根目录规范为准；本文件只补充本项目特有的信息。

## 这是什么

全站部署与运维：一台服务器上所有子项目容器的共享设施 ——
反向代理、端口分配表、部署脚本与部署约定。不含任何业务代码。

## 档位

workflow_tier: LIGHT

判档理由：没有后端业务与数据持久化，不依赖需要密钥的外部服务（凭据明确不入库），
文件规模很小。**升级触发条件**：一旦引入自动化流水线、或需要在仓库内托管凭据，
就升级到 FULL（补 `constitution/`、`specs/`、`.ai/`）。

## 怎么跑

见 [`README.md`](./README.md)。核心命令：

```bash
./deploy/scripts/deploy.sh <子项目名|proxy|all>
```

## 本项目特有约束

- **共享设施只在本目录改**；任何子项目都不得修改反代、证书、网络等共享配置。
- **端口先登记再使用**：在 [`ports.md`](./ports.md) 登记，不得与已分配端口冲突。
- **真实凭据不进仓库**：服务器 `.env`、证书、密钥由使用者保管。
- 不托管业务代码，不引入子项目依赖。
