# 候选图标目录

这里放 Logo 评选的候选图（当前 **31 张**），**图片本身不提交 git**（见 `../.gitignore`）。
本 README 保留在仓库里，保证目录结构与说明可见。

## 命名

`NN_名称.png`，例如 `01_无限连接.png`：

- `NN`：两位编号，决定展示顺序（01–99）；
- `名称`：显示在卡片上的中文名；
- 扩展名：`.png`。

服务启动时扫描本目录。编号重复时保留第一个并打印警告。

## 后台直接上传（推荐）

管理员登录 `/admin` →「上传图标」可选择一张或多张 PNG 上传：

- 单张 ≤ 5 MB，仅 PNG；文件名会自动清洗，编号取 01–99 中最小空位；
- 最多 99 张；上传成功后立即生效，前台下一次轮询出现，无需重启；
- 文件只写入本目录，不写数据库。

## 本地

图片已就位，直接 `npm run dev` 即可。

## 部署

服务器 `git pull` 后本目录只有 README，可以手工上传图片：

```bash
# 在本地仓库根执行
scp -r toupiao/assets/icons/*.png <用户>@<服务器>:/srv/utility-site/toupiao/assets/icons/

# 服务器上让容器内 uid 1000 可写（后台上传也要写）
sudo chown -R 1000:1000 /srv/utility-site/toupiao/assets/icons
```

也可以先启动容器，再由管理员在后台逐张/批量上传。Docker 以**可写**卷挂载本目录：

```yaml
- ./assets/icons:/app/assets/icons
```

缺图时服务不会崩：前台显示“图标尚未上传”，后台显示警告；补齐后重启容器即可
（后台上传的图片不需要重启）。
