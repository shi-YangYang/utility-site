# Roadmap — toupiao

> 本文件描述阶段方向，不替代具体 Spec。每个阶段的落地在 `specs/` 里另开 Spec。

## Phase 0 — Prototype（跳过）

项目规模小，不单独做原型，直接进入 MVP。

## Phase 1 — MVP　**已完成（2026-11-04，独立验收 PASS）**

目标：跑通“钉钉登录 → 20 选 5 → 实时票数 → 后台管理 → Docker 部署”的完整闭环。

范围：

- 钉钉 OAuth2 扫码登录（凭据走环境变量引导）。
- 20 个候选图标展示；每人最多 5 个不同图标，每个 1 票，可取消/改投。
- 前台实时排名与票数（轮询），不公开投票人。
- 管理端：口令登录、总览、投票人明细、开关投票、CSV 导出、重置（二次确认）。
- SQLite 持久化；单容器 Docker；端口与部署文档；CI 校验。

对应 Spec：`specs/spec-001-mvp-logo-vote/`

明确不在 Phase 1 内：真实域名/HTTPS 接线、钉钉工作台免登、图标在线管理、
消息通知、投票实时推送。

## Phase 2 — Productization（进行中）

- 钉钉登录配置后台化（站点地址 / AppKey / AppSecret / corpId，加密落库，保存即生效）——
  对应 `specs/spec-002-dingtalk-admin-config/`，实施完成待验收。
- 域名、HTTPS 与真实钉钉应用回调上线；服务器部署（Caddy + CD）。
- 把图标上传做成部署脚本的一部分，减少手工步骤。
- 投票结果归档（如导出 PDF/结果页快照），供品牌决策留档。

## Phase 3 — Expansion（未规划）

若还有类似评选需求，复制本项目改配置即可；是否抽成通用投票工具需要单独讨论，
不能因为“以后可能用到”而提前复杂化。
