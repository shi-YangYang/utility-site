# Roadmap — recording

> 本文件描述阶段方向，不替代具体 Spec。每个阶段的落地都在 `specs/` 里另开 Spec。

## Phase 0 — Prototype（未做）

没有单独的原型阶段。项目足够小，直接进入 MVP。

## Phase 1 — MVP　← **当前阶段**

目标：跑通完整的"员工录音 → 上传 → 管理员查看"闭环。

范围：

- 员工端：口令进入 → 填姓名 → 录中文、英文各一段（各约 60 秒）→ 提交。
- 服务端：校验口令与姓名、接收上传、用 ffmpeg 统一转成 WAV、落盘、维护索引。
- 管理端：管理口令进入 → 列出所有提交记录 → 试听与下载。
- 同名重复提交按覆盖处理，一人一条最新记录。

对应 Spec：`specs/spec-001-mvp-recording-collection/`

明确不在 Phase 1 内：员工名单、未交名单、统计汇总、音色分析、账号体系、HTTPS 部署、CI。

## Phase 2 — Productization（待讨论）

方向示意，**尚未与用户确认，不得当作已定计划**：

- 接入正式员工名单，支持"应交 / 已交 / 未交"视图。
- Docker 化部署 + CI/CD 落地（涉及仓库根目录结构决策，见 `tech-stack.md` 待确认项）。
- HTTPS 部署到公司内网服务器。

## Phase 3 — Expansion（未规划）

可能方向：多语言段落、多段落采集、与下游音色分析流程打通。
依据不足，不擅自规划，需要时先与用户确认。
